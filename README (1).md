# Gallery photo assets

Put photographs that you own or have permission to publish in this folder. Prefer optimized JPG, PNG, or WebP files; use descriptive filenames such as `ieee-edtm-2024.jpg`. In `gallery.html`, reference them with relative paths such as `assets/gallery/ieee-edtm-2024.jpg`, and add descriptive alternative text. The current photo repository is an album index that links to the original public archive because the source images were not available as downloadable repository files during this update.
