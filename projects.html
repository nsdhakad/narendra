NARENDRA SINGH DHAKAD / PROJECTS

Research projects

Selected projects in SRAM-based in-memory computing, emerging memory, logic design, and AI acceleration.

PORTFOLIO/PROJECTS

Selected project portfolio

Digital In-Memory Compute Engine for Improved Area Efficiency

A digital in-memory compute engine concept for next-generation compute CPUs and AI workloads.

Data Sorting using 6T SRAM Based In-Memory Computing

Performs data sorting using in-memory computing, with a focus on reduced latency and improved area efficiency.

Configurable Multi-Port Memory Architecture

Configures a single-port SRAM macro to support 1-, 2-, 3-, or 4-port operation for read and write access.

SHA-CNN: Scalable Hierarchical Aware CNN for Edge AI

A hierarchical CNN approach described as scalable across classes and levels, with reduced computation.

Reconfigurable and Efficient In-Memory Computing using SRAM

Boolean conversion using 6T/10T SRAM and low-latency content-addressable-memory string search.

Memristor-Inspired Digital Logic Circuits Design

A Y₂O₃-based memristor model used to design optimized digital logic and combinational circuits.

Analog In-Memory Computing using RRAM

A 1T2R memory bitcell concept for high-density memory and multiply-accumulate (MAC) operations for neural networks.

ReCAM: RRAM Digital Content Addressable Memory

A 3T1R bitcell and content-addressable memory architecture for parallel string search, targeting low latency and energy.

Hardware Accelerator for Deep Neural Network

A resource-efficient fully connected DNN design using data-flow reuse and efficient weight/bias addressing; evaluated on a Virtex-7 FPGA.

BitMAC: Bit-Serial Computation-based Efficient MAC for DNN Accelerator

A bit-serial MAC approach including a 1-bit multiplication bitcell and power-gated 8-bit MAC design.

Configurable Activation Function for Variable Bit-Precision DNN Hardware Accelerators

A reconfigurable activation function using CORDIC and ROM; LeNet and VGG16 were deployed on FPGA for evaluation.

Soft-Error-Hardened Voltage-Bootstrapped Schmitt Trigger

A reliability-oriented Schmitt trigger study considering radiation tolerance and threshold-voltage sensitivity to temperature.

Voltage-Controlled Oscillator using Injection Locking Technique

Ring and LC-based VCO designs using injection locking, evaluated for phase noise, tuning range, voltage swing, and power.
